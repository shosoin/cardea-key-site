# cardeakey.org

Source of the landing page for **Cardea Key**, served with GitHub Pages at <https://cardeakey.org>.
Static HTML and CSS only: no JavaScript, no cookies, no trackers.

Cardea Key is an open-source security key in development (FIDO2, OpenPGP, PIV, OATH on the RP2350,
with a secure element and a fingerprint sensor). Its source code is not public yet.
